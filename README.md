# 一步一背

面向全国统考 333 教育综合与 311 教育学专业基础考生的网页学习工具。把教材拆成小要点，按“阅读、提示回忆、独立回忆、对照自评”学习，再按间隔复习。

## 直接使用

**[点击打开一步一背（试运行）](https://guorineng001-byte.github.io/yibuyibei/)**

在手机或电脑浏览器里使用，无需注册、下载源码或运行命令。打开后点“选择学习内容”，选好章节即可开始。预置文字卡片可直接学习，连接原书 PDF 是可选操作。

发给手机或朋友时，请分享上面的 HTTPS 网址。`http://127.0.0.1:4318/` 仅供运行程序的电脑自己访问，发到手机不能打开。线上网址不依赖这台电脑开机。

首次联网打开，等到页面显示“离线背诵已就绪”，之后可离线学习。iPhone 可通过 Safari“分享 → 添加到主屏幕”；安卓可使用浏览器的安装应用或添加到桌面功能。

若在聊天应用中打不开，可复制上面的完整 HTTPS 网址到手机系统浏览器再试。进展见 [开发交接](HANDOFF.md)。

## 开始学习

1. 首页选择学习内容，依次展开书目、分篇、章节和知识点。
2. 在学习设置中选择 333 或 311。院校可留空，也可填写自己的目标；鼓励支持完整和精简两种方式。
3. 无需先连接 PDF，即可使用预置文字卡片、检索、背诵和复习。需要原页时，在书库选中对应分册，点“重新连接本地原书”。
4. 选择同一册、同页序的 PDF，核对页数并确认。教心、教原分册支持 157 页原书及同页清理副本；中外教育史分册为 215 页。来源页按 PDF 页码保存，包含封面和目录。

原书文件连接成功后保存在当前浏览器，随后可离线对照。

## 自由安排与连续阅读

在“选择学习内容”中，按书目、分篇、章节、节／考点勾选范围，可跨书目选择，不限数量。目录始终保留全部可学内容；“全部／到期／未学”和“要点方式”决定本次实际开始哪些要点，底部显示阅读与背诵数量。自选范围按原书顺序学习。

勾选整章或整节后，点“整批设为只阅读”或“整批恢复背诵”。批量操作修改勾选范围的全部要点，不受上方本次筛选影响，也不清空已读、掌握或回忆记录。只阅读不参加间隔复习；恢复背诵时保留已有到期日期，只读过且尚无到期日期的要点当天加入复习，未学要点仍为未学。

要连续阅读，选择范围，把“要点方式”切到“只选阅读”，点“开始连续阅读”。每次点“已读懂，继续下一点”推进；可展开“本次目录”跨知识点或章节跳转，也可回看上一要点。混合会话按每个要点自己的方式衔接，跳到后面后仍会补齐前面未处理的内容。

点计时按钮暂停，或“暂停并返回”休息；首页“继续上次的要点”回到原位置。刷新与完整备份恢复均保留本次范围、当前位置和已处理记录。阅读只记录已读，不增加独立回忆评分或掌握程度。

## 备份与恢复

“学习设置 → 导出学习备份”下载 JSON，包含考试类型、院校、鼓励偏好、复习间隔、整理内容、阅读偏好、学习进度、当前会话和题目练习。恢复时先选择 JSON，核对数量后确认；恢复会替换当前内容与进度，在首页继续原会话。原 PDF 不在 JSON 内，请单独保留并按需重连。

数据存放在当前网站来源下的 IndexedDB，数据库名为 `yibuyibei-public`。不同设备、浏览器、域名或端口不会自动同步。清理网站数据会清除学习记录和连接的原书，建议定期导出备份。

## 用自己的 Agent 整理教材

在“我的书库 → Agent 学习包”中可导入 JSON 文件或粘贴完整 JSON，预览来源、页码、新增数量和修订对比后确认。新内容默认待校对；原书核对后再学习。可先载入原创示例熟悉流程，示例不会自动预置进学习库。

导出支持当前章节和整本书，只带内容与校对状态，不带个人设置、勾选偏好、学习进度或原文件。把导出包和下一节教材片段交给自己的 Agent，沿用 ID 继续整理。重复导入不增加重复条目；默认保留已有内容，明确采用修订时只重置正文改变的要点进度。

程序内“新手教程”提供整理提示词、原创示例与操作说明。完整教程见 [国内 AI 新手教程](public/guide/AI_STARTER_GUIDE.md)，格式见 [数据约定](DATA_MODEL.md)。

## 维护与交接

书目元数据在 `src/books.ts`，章节及纸面页码映射在 `src/catalog.ts`、`src/eduCatalog.ts`，内容加载目录在 `src/contentCatalog.ts`。学习包与持久化字段约定见 [DATA_MODEL.md](DATA_MODEL.md)。

每次对话结束更新 [开发交接](HANDOFF.md)，阶段完成另留阶段交接文件。新对话从该文件中的当前阶段和下一步继续。

发现内容问题时，请记录书目、章节、知识点标题、PDF 页码和预期文字；程序问题请附触发步骤与浏览器信息。反馈前可导出备份留存。后续整理其他教材时，可由用户自己的 Agent 按现有数据模型准备学习包。

## 已知问题

- 教育研究方法尚未提供，311 页面会显示待补充。
- 本地原书需要用户自行连接；完整 PDF 只作为本地交付文件，不随静态站点构建打包。
- 首次使用文字识别需要联网下载 Tesseract 资源；已接入的文字卡片学习无需 OCR。部分网络环境可能无法取得这些资源。
- 同页数的其他排版仍可能导致原页定位错误，连接前须确认是同一册、同页序的版本。
- 当前线上入口的大陆手机真机联网验收待完成，进展见开发交接。
