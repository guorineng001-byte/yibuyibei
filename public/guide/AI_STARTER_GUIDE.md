# 用自己的 AI 整理教材

在“一步一背 → 我的书库 → Agent 学习包”中，先用原创示例熟悉导入、校对和学习，再处理自己的教材。现有预置内容可以继续使用，无需重新整理。

## 先做完一个小节

1. 准备一节或 3–5 页教材，记下书名、科目、原 PDF 总页数、本次处理的 PDF 页码。PDF 页码包含封面和目录。扫描材料可以提供清晰截图和原 PDF 页码；文字材料可直接复制。
2. 打开自己使用的 AI。可从 [Kimi](https://www.kimi.com/) 开始，其官方说明列出了 PDF、图片和文字文件处理能力；附件能力和限制见 [Kimi 文件能力说明](https://www.kimi.com/help/others/capability)。也可使用 [DeepSeek](https://chat.deepseek.com/) 或 [豆包](https://www.doubao.com/)，粘贴已经整理出的文字。
3. 复制程序中的“整理提示词”，把教材片段一起交给所选工具。说明总页数和原 PDF 页码，让它输出完整学习包 JSON。已有书目继续整理时，先从程序导出当前章节学习包，一并提供，要求沿用 ID。
4. AI 给出 .json 文件时下载保存；只给代码框时复制框内全部内容。回到“导入学习包”，选择文件或粘贴文本，点“预览导入”。不需要自行写程序或申请 API 密钥。
5. 核对书名、来源、总页数、新增数量及修订对比，再点“确认导入学习包”。新整理内容默认是待校对。
6. 在书库选中教材，通过“重新连接本地原书”选择自己的文件。点卡片右侧整理按钮，对照原页检查文字、标题、层级和来源；勾选已校对并保存后，即可学习和检索。

## 接着整理下一节

从程序导出这本书的当前章节或整本书学习包，继续交给 AI，附本次新增材料。让它保留同一条目的 ID，只给新增条目分配新 ID。再次导入会显示哪些内容新增、哪些已经存在。

默认保留已有内容，重复导入相同包不会重复增加要点。需要采用修订时，展开对比并勾选“采用上方修订”。只有正文改变的要点会重置进度；标题或层级调整不重置正文掌握记录，其他内容和回忆事件保留。给已校对知识点追加要点会让该知识点重新待校对，原有要点进度仍保留。

学习包不删除未出现的旧内容，也不带入个人进度。跨设备续学请用“学习设置 → 导出学习备份／恢复备份”，原 PDF 单独保留。

## 已知问题与处理

- AI 可能识别错字、误判层级或编造来源页。文字无法辨认时保留待核对说明，来源页不确定时允许留空，确认前不要标记已校对。
- 文件过大、对话过长或额度不足时，缩小到几页或一小节，保存已有学习包后续接。Kimi 官方也建议对大文件分段处理，见 [会话常见问题](https://www.kimi.com/help/others/chat-issues)。
- JSON 报错时，把程序的具体错误发回原 AI 对话，让它保留 ID 并返回完整 JSON。不要只复制截断的一段或把“其余同上”当作内容。
- 各工具的界面、附件能力、额度与收费以当前产品页面为准。本程序不代传教材，不接入付费 AI 后端；文件与文字由你主动交给所选工具。只提供本次需要整理的教材片段，原书与个人学习备份单独保留。
- 第三方教材整理内容的来源和使用范围应如实填写；代码的 MIT 许可证不代表教材内容可自由分发。
